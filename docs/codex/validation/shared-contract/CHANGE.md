# Shared evidence contract candidate

Root cause: mapping, residual repair and key validation assign different authority to the same accepted input, allowing balancing edits to erase a mapped figure without replacement evidence.

Generic evidence rule: an accepted home/value claim remains a claim when its colour or confidence changes; an unexplained residual is not replacement evidence. The claim applies only to its exact home while that home still holds the claimed value. A changed headline requires its named target, not a coincidentally equal number elsewhere in the disclosure.

Implementation: reuse Writer.served as the single residual eligibility source in Writer.write, the terminal plug tool and its candidate selection. Remove the terminal tool's separate contradictory proven-value policy. Keep supported mapping corrections possible. Reuse existing key snapshots and named key targets; remove the unrelated-number exception. This is a bounded architectural correction, not a complete replacement of the pipeline.

Museum pins: tests/test_plug_boundary.py exercises a red mapped claim with trusted/force-lock residual calls, exact-home scoping, correction and terminal tool consistency. The key snapshot exhibit in tests/test_pipeline_museum.py rejects an unrelated printed alternative and accepts an explicit named target correction.

Known limits: direct non-plug repair writes and whole-transaction proof preservation still need verification. The CLP/DFE interpretation component test found reserves and cash-flow totals but missed capacity-event classification. No cold acceptance or readiness claim is made. Commit/dispatch require all three balanced replay gates and targeted readiness after final integration.


Event integration: discovery now previews the SAME structural eligibility used by forecast preservation against the original workbook. The reviewer receives immutable cell IDs, economic labels/sections and prior/actual values; classification is separate from actual mapping success. Both review entry points use the shared candidate context and decision tool. Production review applies the existing freeze path after classification. This fixes the missing review hand-off rather than duplicating economic rules in code.

Residual loop: flag-only journal entries no longer count as a numerical repair. A refused chosen input cannot be bypassed by starting another round solely because the check was marked red.
